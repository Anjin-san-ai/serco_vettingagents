    Reading the scene

    Generated from the same config the 3D scene reads, so the two cannot disagree. State is carried by five channels — chip, ring shape, motion, elevation and colour — because measured greyscale luminance is not monotonic across these states (idle 0.72, working 0.20, waiting 0.73, escalated 0.12, complete 0.53), so brightness alone would not separate them. Correcting an earlier claim of ours that it would.
