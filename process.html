As-is process maps

Four as-is process models, script-validated

Generated and validated with the okhp3-visual-process-modeling skill from the OKHP3/skillz BP-SKILL suite. The source of truth remains the Visio originals.

Shown as source, not yet as diagrams. These are the validated model definitions, which is why they read as code rather than as swimlanes. Rendering them as proper SVG swimlane diagrams — with the RTW pushback loop called out, since that loop is where the 23% comes from — is the next piece of work. Until then this section is for the record rather than for the room.

Worth knowing if you use that skill. Its bundled syntax reference documents a bracket DSL ([ Task ], { Decision? }) but its validator parses a different declaration DSL (task t1 "Label") and rejects the documented form outright. The maps here are written to the validator's grammar, because that is the one that actually gates. The skill also declares its own evals not-run, so every map was read by hand against the syntax reference as well as validated by script.
